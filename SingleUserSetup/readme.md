# Single user Setup in Git

* we can add folders in repo by just "git add" and see the status and commit as usual.

* We can access previous commands of terminal by up arrow key.

/------------------------------------------------------------------------------------------------------------------------

# .gitignore

* we can list the file and folder in the .gitignore file to be ignored by git.
* by "foldername/" we can ignore whole folder.
* by "foldername/filename" we can ignore particular file in that folder.

/------------------------------------------------------------------------------------------------------------------------

# .gitkeep

* git does not track the empty folders or empty directories.
* If we want git to track that folders then we can a file in that folders named ".gitkeep".
